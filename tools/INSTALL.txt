Kakarot HD Save Syncer @VERSION@

DRAGON BALL Z: KAKAROT on Steam has a standard build and an HD build, and each keeps its own
saves. This plugin keeps them in step: when one build saves, the same slot is written in the
other build's format, and at game start any newer save from the other build is brought over.

INSTALL
1. Back up your saves: Steam\userdata\<your Steam id>\851850\remote
2. Copy kakarot-hd-save-syncer.asi and xinput1_3.dll into the exe folder of the build you
   play on Windows:
     Standard: ...\DRAGON BALL Z KAKAROT\AT\Binaries\Win64\
     HD:       ...\DRAGON BALL Z KAKAROT\dlc\Remaster\AT\Binaries\Win64\
   If that folder already has Ultimate ASI Loader as xinput1_3.dll, keep the one there.
3. Make sure Steam Cloud is enabled for the game (game Properties > General in Steam).
One install on one Windows machine is enough. The other device (for example a Steam Deck)
needs nothing: it receives the saves through Steam Cloud. Installing into both build folders
also works.

LOG
kakarot-hd-save-syncer.log, in the same folder as the .asi.

IF THE GAME REPORTS "NO SAVE DATA" OR REFUSES TO SAVE
Fully restart the Steam client (Steam menu > Exit, then start Steam again), then start the game.

UNINSTALL
Delete kakarot-hd-save-syncer.asi and xinput1_3.dll from the exe folder (keep xinput1_3.dll if
another mod uses it). You may also delete kakarot-hd-save-syncer.log and
kakarot-hd-save-syncer.manifest there. Your saves are untouched.

The plugin never deletes a save. Deleting a slot in one build leaves the other build's copy.
