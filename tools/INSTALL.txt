DBZ Kakarot Save Syncer @VERSION@

A mod for DRAGON BALL Z: KAKAROT on Steam that automatically keeps your saves in-sync between
the standard and HD versions of the game, even across devices. Play one version, and your
saves appear in the other. No manual "Transfer Save Data" needed.

INSTALL
1. Back up your saves: Steam\userdata\<your Steam id>\851850\remote
2. Extract all the files from the zip into the HD version's folder:
     ...\DRAGON BALL Z KAKAROT\dlc\Remaster\AT\Binaries\Win64\
   If that folder already has Ultimate ASI Loader as xinput1_3.dll, keep the one there.
Steam Cloud must be enabled for the game (it is by default; see game Properties > General).
A Steam Deck or second PC that plays the standard version needs nothing installed: it receives
the saves through Steam Cloud. If you only play the standard version on Windows, install into
...\DRAGON BALL Z KAKAROT\AT\Binaries\Win64\ instead.

LOG
dbz-kakarot-save-syncer.log, in the same folder as the .asi.

IF THE GAME REPORTS "NO SAVE DATA" OR REFUSES TO SAVE
Fully restart the Steam client (Steam menu > Exit, then start Steam again), then start the game.

UNINSTALL
Delete dbz-kakarot-save-syncer.asi and xinput1_3.dll from the exe folder (keep xinput1_3.dll if
another mod uses it). You may also delete dbz-kakarot-save-syncer.log and
dbz-kakarot-save-syncer.manifest there. Your saves are untouched.

The plugin never deletes a save. Deleting a slot in one build leaves the other build's copy.
